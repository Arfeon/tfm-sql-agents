# Proceso de trabajo del TFM

Esta carpeta es el **rastro de cómo hice el proyecto**, no documentación para usarlo. La guardo porque forma parte de la memoria del TFM (incluido cómo usé la IA para acelerar el trabajo), pero si has llegado aquí buscando qué es GraphSQL o cómo se usa, no es tu sitio.

Qué hay:

- **`diario/`** — diario de trabajo, una entrada por día: qué hice, qué aprendí y qué decidí. En primera persona.
- **`investigacion/`** — notas de investigación previas a cada decisión técnica (embeddings, Neo4j, LangGraph, stack). El razonamiento largo; la decisión ya resumida está en el diseño.
